# Specs

Specs describe what both packages must do, independent of language. A spec
starts as a proposal; once accepted, the agreed text lives here and changes only
through new proposals.

Planned specs:

| Spec | Purpose | Status |
| --- | --- | --- |
| Methods | What SCEPTRE computes: QC, models, tests and defaults | Not started |
| Data model | How `SingleCellExperiment` and AnnData/MuData objects map to each other | Not started |
| Result schema | Columns, types and meaning of result tables, with a version number | Not started |
| Parity | When the R and Python implementations count as agreeing: exact for deterministic steps, shared random draws for resampling, statistical agreement on full runs | Not started |
| Compatibility | Which package versions support which schema version | Not started |
